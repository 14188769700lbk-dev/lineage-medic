## Engineering-fit judgment

This section is an assessment, not an organizer statement.

The AWS event has the better probability-adjusted fit. A fresh **Change Sentinel** could watch a sanitized change request, inspect an allowlisted repository snapshot, build an owner-specific checklist, run deterministic evidence gates, and surface only unresolved decisions. It would reuse domain knowledge, not LineageMedic code, and its submission would disclose the earlier product as prior inspiration. That keeps the new-project boundary honest.

The Google event offers more prize slots and stronger individual awards, but its mandatory infrastructure is substantially broader. Starting it before ClauseTrace is publicly submitted would trade a nearly complete, sponsor-evidenced entry for a rushed cloud migration with a stricter deadline. The headline pool alone does not justify that switch.
